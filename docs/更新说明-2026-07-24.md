# APPDO 关于我们独立站更新说明

发布日期：2026 年 7 月 24 日

## 本次更新

### 联系方式贴纸

- 在「找到合适的合作方式」标题旁加入可交互的 Contact me / @appdo_bot 联系贴纸。
- 深色与浅色主题使用一致的高对比效果，避免文字在不同主题下难以辨认。
- 贴纸仅在用户滚动接近合作模块时加载，减少首屏 WebGL 初始化造成的卡顿。

### 页面性能与流畅度

- 产品矩阵的鼠标跟随光效改为每个浏览器动画帧最多更新一次，减少高频指针事件触发的重复布局计算。
- 缓存产品卡片边界信息，避免鼠标移动期间反复调用布局测量。
- 产品 Logo、合作品牌轮播、成长时间线和生态系统装饰动画在离开视口后暂停，回到可见区域时继续播放。
- 合作品牌的远程图标改为懒加载、异步解码和低优先级请求，降低非首屏资源对页面加载的影响。
- 产品矩阵数据使用缓存计算，减少语言或页面状态变化时不必要的对象重建。

## 保持不变

- 没有修改现有动画的视觉效果、时长、缓动、交互方式和布局结构。
- 中文、日文、英文内容与深色、浅色主题均保持原有设计。
- GitHub 推送与 Cloudflare Pages 部署是两个独立步骤：本项目的 Cloudflare Pages 使用 Direct Upload，推送到 GitHub 不会自动发布线上版本。

## 验证结果

- ESLint 检查通过。
- TypeScript 类型检查通过。
- Next.js 生产构建通过。
- 本地浏览器已验证首屏、产品矩阵、成长时间线、生态系统、合作品牌、合作模块和主题切换。
- 已验证联系贴纸不会在首屏加载，并会在接近合作模块时正常加载和交互。
